The route under investigation

Quote-Execution Mismatch in Tempo Multi-Hop Swaps

The question: Can a swap system fail to simulate and estimate the output of a route that would execute successfully in real life and therefore be unable to compare it with other routes? We tested different route lengths, hook types, input amounts, and liquidity conditions to find where quoting and execution diverge. The gap appeared in a Tempo multi-hop route, cUSD → PathUSD → USDT0: for certain inputs, V4Quoter returns no quote, even though the swap succeeds on a fork when the transaction prepares the input first.

How the two paths diverge

The affected quote simulation can reach the hook before the required input balance is prepared. A funded transaction supplies the input first, then runs the same route.

What the evidence supports

For certain multi-hop Tempo routes, the examined UniRoute quote path can fail to prepare the balance required by hook execution. An executable route may therefore have no usable quote for route comparison. A fix must produce both an accurate quote and a compatible funded execution plan.

This dashboard does not claim measured production impact, user loss, or better prices. Those claims require production traffic data and same-block comparisons against other executable routes, including gas.

Solution

No fix is presented yet.

The controls rule out the broad claims that “multi-hop is broken” or “hooks cannot be quoted.” The reported gap is narrower: for certain amounts on this Tempo route, the quote simulation reaches a hook without the input balance that a funded transaction can prepare before execution.
