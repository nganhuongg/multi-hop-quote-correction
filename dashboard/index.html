01Overall mechanism

A route defines the ordered pools. A quote simulates that route to estimate output. A swap executes it with real token settlement. The analysis compares both processes from the same starting state.

04Finding

The problem is not “multi-hop is broken” and it is not “Tempo has no liquidity.” Most cases work. The mismatch appears when the quote preview reaches a custom conversion step without first preparing the input that the real swap can prepare.

QUOTE PROCESSCan fail early
  1. 1Start route preview
  2. 2Enter custom Tempo pool
  3. !Required input is not prepared
  4. 4No result reaches route comparison
REAL SWAP PROCESSCan complete
  1. 1Prepare the user's input
  2. 2Run both pool conversions
  3. 3Send output to recipient
  4. ✓Completed amount can be measured
GENERAL PROBLEM A route may be executable, but disappear from route comparison because its quote preview did not reproduce the same preparation steps as execution.
02
SOLUTION

Validated quote recovery on the pinned Tempo fork.

The standalone prototype composes supported Tempo hop quotes and admits a candidate only after matching full Universal Router execution. At block 41,183,156, the 25 cUSD route recovers 24.997499 USDT0; the 1 cUSD PathUSD route reconciles 0.999800 gross swap output with a 0.999479 wallet increase and a separate 0.000321 PathUSD gas charge. These are recorded fork results, not live quotes or a production UniRoute deployment. The proposed UniRoute patch still needs its real validator wired into the private service.
